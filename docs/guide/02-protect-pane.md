# 02 · Protect a pane

A protected pane shows a lock on its Pane row instead of the close button.

- **Protect / unprotect:** right-click the Pane row → **Protect** (it reads **Protected** while on).
- An orchestrator (a tab labelled `orch-*`) is protected from the start.
- **Close pane** is off for a protected pane, and says so in the menu. On a tab with only that pane the item is **Close tab**, off the same way.
- Closing the tab, Workspace or Session that holds one names the protected panes first. **Cancel** is the default;
  **Unprotect and close** is the deliberate way through.
- The mark lives in this app only (it is not a herdr setting) and is dropped once the pane is gone.
